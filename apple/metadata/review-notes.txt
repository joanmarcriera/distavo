Distavo is a bring-your-own-server app: transcription runs fully on-device (Apple Silicon, WhisperKit). The optional summarisation step uses an Ollama server the USER runs themselves — on their own Mac or their own network. By design there is no cloud service, no account, and no telemetry.

What you will see on a review machine that has no Ollama server installed (items 1–2 address the 1.8.0 (9) review, submission 337cdeaf-0229-45a6-8846-11d026537b65; item 3 addresses the latest microphone-permission wording rejection):

1) Settings -> Connections -> "Test connection": the two Ollama indicators show AMBER with an explanation that Ollama is not running on this Mac, that recording and on-device transcription still work, and how to complete setup (install Ollama or point at a server on the network). In 1.8.0 these were unexplained red dots; this version fixes that.

2) Local Network permission: with the default configuration both Ollama endpoints are localhost, so the app never uses the local network — macOS therefore does not prompt and does not list Distavo under System Settings -> Privacy & Security -> Local Network. This is expected macOS behaviour, and the in-app Permissions helper now says so explicitly ("Not needed with your current settings"). To see the prompt: in Settings set "Server Ollama URL" to any LAN address (for example http://192.168.1.10:11434), open "Check permissions...", and click "Continue" — the macOS Local Network prompt appears and Distavo becomes listed in the pane.

3) Microphone permission wording: the one-time explanation shown before the macOS microphone prompt uses the neutral action "Continue". The Permissions helper also uses "Continue" while microphone access is undetermined. If access was denied, Distavo offers "Open Microphone Settings" instead of requesting again.

To exercise the full pipeline end-to-end: install Ollama from https://ollama.com, run "ollama pull llama3.2", leave it running, then use the menu-bar item "Record meeting" (or drop any short audio file into the watched folder shown in Settings). Transcription happens on-device; the Markdown note is completed via the local Ollama and written to the notes folder.

1.11 — built-in transcription model downloads:

On first use, the built-in transcription engine downloads a Core ML model from Hugging Face into ~/Library/Application Support/Distavo/models. Sizes: Whisper large-v3 turbo ("Best") 632 MB, Whisper small ("Compact") 463 MB, NVIDIA Parakeet TDT 0.6B v3 ("Fast") ~460 MB, and the two Barcelona Supercomputing Center Catalan/Spanish models 3.1 GB each. Settings offers "Download now" to fetch a model ahead of the first meeting (with a running total, progress, and Cancel) and "Remove downloaded models" to delete the one folder Distavo manages. Downloads are verified against a manifest of SHA-256 hashes before use; if a download fails because the Mac is offline, the recording waits and is retried automatically rather than being marked failed.

This flow needs no account and involves no telemetry. The App Store build links no third-party binary framework for this feature — the models are downloaded, not bundled.

On a review machine with less than 16 GB of memory, the two Catalan/Spanish models are hidden from the model picker by design (they are not offered, not merely disabled) since they do not run acceptably below that.
