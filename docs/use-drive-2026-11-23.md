# What changed for your own days, and how to try it (drive 2026-11-23)

Branch `feat/drive-1123-use` (on `feat/drive-1122-notes`). Nothing released, tagged or version-bumped.
Everything below is **off for an existing config** (the Tasks wording only changes with "Check names in notes" on) and on for fresh installs only, as for every 1.17+ option; for your
own Mac you switch it on once (Settings › Notes).

## 2. Notes that stop guessing
Settings › Notes › **Names and owners** › "Check names in notes" (key `summarise.name_check`).
- **Owner is you.** Set "Note owner" (Settings › Notes › People) to your real name; the prompt pins it and the note
  never takes a name from the audio, a recording title or a topic word.
- **One person, several spellings.** Press "Open…" next to "Names file": a plain file `names.txt` in
  `~/Library/Application Support/Distavo`. One line per person: `Right Name: wrong spelling, another wrong spelling`.
  Those spellings become the right name in the note (whole words, exact capitalisation, so `Marc: Mark` leaves "mark it done" alone; Highlights, Speakers, evidence quotes and
  the corrections list are never touched); the footer says how many were merged. A line with only a name or term feeds the summary as a spelling aid.
- **Playback of a recorded training.** Pick the template **Training playback** in the stop sheet (or on the folder); the
  note has Topic / Key points / Steps and terms only, no attendees, no follow-up, and a footer line says why.
  Without a pick, `summarise.non_meeting_guard` still detects a narrated course by itself.
- **Action items have an owner only when the transcript names one.** The Tasks prompt now says so, and after the note
  is written any owner nobody mentioned becomes `unassigned` (footer counts them). Needs "Action items" on in the same pane.

## 3. Sales calls
- Pick **Sales call (call log)** in the stop sheet. The note has: Who, Firm, What they said about their work, Objections
  raised, Next step and date, What we promised. Anything not said is "none stated".
- Settings › Notes › **Sales calls**: choose the hand-off folder. No hand-off folder was named anywhere on 23 Nov, so it is a setting; point it at the
  folder the sales tool reads once that is decided.
- Notes… › select the note › **Export Sales Call…** writes `<folder>/<yyyy-MM-dd>-<firm>/call.md` and copies the audio
  beside it (re-running refreshes `call.md`, never duplicates the audio). Switch on "Export sales calls automatically" and it
  happens as soon as the note is written. A missing folder (unmounted drive) is a notification, nothing else.

## Try it in two minutes
1. Settings › Notes: switch "Check names in notes" on, set Note owner to your name, choose a hand-off folder.
2. Drop a test recording in the recordings folder, or record 30 s; at Stop choose "Sales call (call log)".
3. When the note appears: Notes… › Export Sales Call… and look in the hand-off folder.

## Three decisions the all-day design still needs (yes/no, with my recommendation)

2. Ask your employer's contact once whether any recording is allowed; a client-owned laptop stays out until a yes? **Recommend yes.**

## Known gaps
- Owner pin for Ollama is the strong "authoritative" block; Gemma and Apple's on-device model get the shorter
  `OwnerIdentity` rule (merging the two is a follow-up).
- Two calls with the same firm on the same day go to `<date>-<firm>` and `<date>-<firm> 2` (a hidden `.distavo-source` file says whose is whose).
- Task owners count as named when the transcript, the participants line, your name, or a names.txt spelling of them says so.
- Regenerate does not re-run the automatic playback detection, but honours a template you picked.
- `names.txt` rewrites in the note only; the transcript keeps what the engine heard (use Settings › Transcription ›
  replacements for the transcript).
