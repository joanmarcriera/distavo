Setup

Set up Distavo in five minutes.

Transcription runs on your Mac with nothing to configure. Summaries need one extra choice: an Ollama server you run, Apple Intelligence on macOS 26 or later (not for Catalan), or the opt-in on-device model. Do this once and every recording becomes a note.

1. Install

Install Distavo from the Mac App Store, or use the free direct download. It needs macOS 14 or later and Apple Silicon. The Catalan and Spanish models need 16 GB of memory or more.

2. Choose how summaries are written

  • Ollama (your Mac or a machine on your network). Install Ollama, pull a model (table below), then in Distavo's Settings enter the server address and press Test connection. If the server is on your LAN, allow macOS Local Network access when asked.
  • On-device, no server. On macOS 26 or later Distavo can use Apple Intelligence (not available for Catalan), or the opt-in on-device model you switch on in Settings.

If you skip this step the first recording is transcribed but its note waits, with the message that the Ollama server is offline. Nothing is lost: set the server up and it finishes on its own.

Which Ollama model for my Mac?

These are suggestions, not guarantees. The only figure published for each model is its download size, so pick a model that leaves clear room in memory for macOS, Distavo's transcription and the model itself. Sizes come from the Ollama library page named in each row; check it before you pull.

Smaller Macs: a smaller model is faster and less accurate, so check your first notes. Any model Ollama can run works; type its name in Settings.

3. Make your first note

Choose Record from the menu-bar icon and talk for a minute, or drop a recording into the watched folder. The first transcription downloads its model once. The note appears as a Markdown file in your notes folder.
